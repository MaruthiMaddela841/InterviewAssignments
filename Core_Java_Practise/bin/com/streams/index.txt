Think about the question you're asking:
                    STREAM
                       │
          ┌────────────┼────────────┐
          ↓            ↓            ↓
       MODIFY       SEARCH        RESULT
          │            │            │
          ↓            ↓            ↓
      filter()      anyMatch()    collect()
      map()         allMatch()    toArray()
      flatMap()     noneMatch()   count()
      distinct()    findFirst()   min()
      sorted()      findAny()     max()
      limit()
      skip()
      
THEN:
             COLLECT
                │
       ┌────────┼─────────┐
       ↓        ↓         ↓
    List       Set       Map
       │        │         │
 toList()    toSet()   groupingBy()
                         partitioningBy()
       
And numeric processing:

Stream<Integer>
       │
       ↓
  mapToInt()
       │
       ↓
   IntStream
       │
 ┌─────┼──────┐
 ↓     ↓      ↓
sum() min()  max()
      ↓
  average()

Memorize these core patterns:
// FILTER
stream.filter(condition)

// TRANSFORM
stream.map(function)

// FLATTEN
stream.flatMap(function)

// SORT
stream.sorted()

// COUNT
stream.count()

// SEARCH
stream.anyMatch(condition)
stream.allMatch(condition)
stream.noneMatch(condition)

// FIND
stream.findFirst()
stream.findAny()

// MIN/MAX
stream.min(comparator)
stream.max(comparator)

// COLLECT
stream.collect(Collectors.toList())

// GROUP
stream.collect(
    Collectors.groupingBy(...)
)

// PARTITION
stream.collect(
    Collectors.partitioningBy(...)
)

// ARRAY
stream.toArray(Type[]::new)

// PRIMITIVE
stream.mapToInt(...)

// SUM
stream.mapToInt(...).sum()

// AVERAGE
stream.mapToInt(...).average()

Count                                count()

Are ALL valid?                       allMatch()

Does NONE exist?                     noneMatch()

Get first                           findFirst()

Get any                             findAny()

Smallest                            min()

Largest                             max()

Convert to collection                collect()

Convert to array                    toArray()

Group                                groupingBy()
